# dsh-dianleida-ecommerce-product-selection
店雷达 DianLeida 1688电商选品 Skill/MCP

## ✨ 功能介绍
Shop Radar MCP集成了五项关键产品选择功能：
- 产品选择库
- 产品排名查询
- 产品数据分析
- 产品类目筛选
- 同类商品图片检索

接入AI后可直接调取1688真实商品数据，自动生成选品结论，无需手动搬运数据。

## 📦 安装方式
在DSH中导入本仓库，或者直接下载压缩包：
[dianleida-skill-v1.1.0.zip](./dianleida-skill-v1.1.0.zip)

## 📋 使用说明
1. 下载压缩包
2. 在DSH插件管理内导入skill包
3. 配置对应1688接口密钥（按需）
4. 即可调用选品、查排名、商品分析能力

## ⚠️ 注意事项
- 本工具仅用于选品研究，遵守平台规则
- 接口额度、频率限制请自行留意
